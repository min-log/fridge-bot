## 결정한 것
- **접속 정보는 application.yml에 아예 적지 않음.** `${DB_URL}`처럼 참조만 두면 테스트에서 값이 없을 때 placeholder 오류가 나서, Spring 표준 환경변수(`SPRING_DATASOURCE_*`, `SPRING_DATA_REDIS_*`)를 그대로 쓰기로 함. 기본값 자리 자체가 없어 실제 키가 들어갈 수 없음
- **로컬 실행은 docker-compose 대신 `bootTestRun`.** 테스트와 같은 컨테이너 설정을 재사용해 설정이 두 군데로 갈라지지 않음. compose는 배포(6주차)에서 작성
- **git 원격은 SSH.** gh CLI 로그인 시 SSH 키를 만들어 등록함. 원격 주소에 토큰을 넣지 않음
- Gradle configuration cache·build cache 켬
