## 쓰는 방법

새 파일 `NNNN-제목.md`를 만들고 아래 항목을 채운다. 결정을 바꾸면 기존 파일을 고치지 않고 새 ADR을 쓴 뒤 이전 것의 상태를 "대체됨(NNNN)"으로 바꾼다.

```markdown
# NNNN. 제목

- 상태: 제안 / 채택 / 대체됨(NNNN)
- 날짜: YYYY-MM-DD

## 배경
## 결정
## 검토한 대안
## AI 제안과 내 결정
(AI 제안과 다르게 판단했거나, AI 제안을 고친 경우에만 적는다)
- AI 제안:
- 내 결정:
- 다르게 한 이유:
## 결과
```

0001~0007은 AI가 제안한 안을 검토해 그대로 채택한 결정이다. 0008부터는 "AI 제안과 내 결정" 항목을 함께 남긴다.
