# 기획: 냉장고 관리 봇

작성일: 2026-11-25

## 1. 문제

혼자 살면서 겪는 세 가지 문제에서 시작했다.

1. **유통기한이 지나서 버리는 음식이 많다.** 무엇을 언제 샀는지 기억하지 못해, 냉장고 안쪽에 있던 재료를 기한이 지난 뒤에 발견한다.
2. **요리를 잘 못해서, 있는 재료로 무엇을 만들 수 있는지 모른다.** 재료가 있어도 메뉴가 떠오르지 않아 결국 쓰지 못한다.
3. **부모님이 가끔 보내 주시는 식재료가 상하는 경우가 많다.** 한 번에 많이 들어오는데 무엇이 있는지 정리하지 못한다.

## 2. 사용자

- **기본 사용자: 혼자 사는 나.** 휴대폰으로 장 본 영수증을 찍고, 냉장고에 무엇이 있는지 확인한다.
- **함께 쓰는 사람(선택): 가족.** 원하면 초대 코드로 같은 냉장고를 함께 볼 수 있다. 예를 들어 부모님이 보내 주신 식재료를 함께 확인한다.

## 3. 목표

| 문제 | 목표 | 해결 방법 |
|---|---|---|
| 1. 유통기한 놓침 | 버리기 전에 알게 한다 | 영수증 사진으로 재고를 쉽게 등록하고, 유통기한 D-3·D-1·당일에 알림 |
| 2. 메뉴를 모름 | 지금 있는 재료로 만들 수 있는 요리를 알려 준다 | 유통기한이 가까운 재료를 먼저 쓰는 레시피 추천 |
| 3. 한꺼번에 들어온 재료 | 많은 재료를 빠르게 등록하고 한눈에 본다 | 직접 입력·영수증 인식, 보관 위치·임박 순 목록 |

## 4. 범위

### MVP (1차)
- 소셜 로그인, (선택) 가족 초대
- 재고 등록·사용·폐기, 보관 위치, 유통기한 (입력이 없으면 카테고리별 기본값)
- 영수증 사진 인식 → 확인 후 재고 등록
- 유통기한 임박 알림 (Web Push)
- 남은 재료 기반 메뉴 추천
- "계란 남았어?" 같은 대화형 질문
- 월별 식비 통계

### 2차로 미룸
- 부족한 재료로 장보기 목록 만들기, 바코드 인식, 여러 냉장고 소속, 답변 스트리밍, 이미지 외부 저장소

### 하지 않을 것
- 칼로리·영양 분석
- 쇼핑몰 연동·결제
- 레시피 공유 커뮤니티
- 네이티브 앱 (웹 PWA로 충분)

## 5. 성공 기준

실제로 써 보면서 아래 숫자로 확인한다. 처음 한 달 사용 기록을 기준값으로 삼는다.

| 기준 | 측정 방법 |
|---|---|
| 유통기한 때문에 버리는 재료가 줄었는가 | 월별 폐기 건수, 폐기 / (사용 + 폐기) 비율 (`inventory_events`) |
| 알림을 받고 실제로 썼는가 | 알림 후 3일 안에 사용 처리된 비율 |
| 추천을 받아 요리했는가 | 추천 후 해당 재료가 사용 처리된 횟수 |
| 등록이 편한가 | 영수증 인식 정확도(품목·금액), 영수증 한 장 등록에 걸린 시간 |

측정 결과는 [결과](결과.md)에 기록한다.
