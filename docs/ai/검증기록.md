# AI 결과 검증 기록

AI가 작성한 코드·문서에서 틀렸거나 사실과 달랐던 것, 그리고 그것을 어떻게 찾았는지 기록한다. 발견 방법을 남겨 두면 어떤 검증 단계가 실제로 효과가 있었는지 알 수 있다.

| 날짜 | 무엇이 틀렸나 | 발견 방법 | 처리 |
|---|---|---|---|
| 2026-11-25 | 설계 초안이 "실제로 가족과 함께 씀"을 사실처럼 적음. 실제 사용자는 1인 | 사람이 실제 상황을 설명했고, 설계 전제와 다르다는 점을 AI가 짚음 → 사람이 방향 결정 | 기획·설계 수정, [ADR 0008](../adr/0008-기본-사용자는-1인-공유는-선택.md) |
| 2026-11-25 | AI가 쓴 회고 초안에 공개할 필요가 없는 내용이 포함됨 | 사람이 공개된 회고를 읽고 지적 | 문서 범위 재정의, 저장소 기록 정리, [ADR 0009](../adr/0009-공개-저장소에는-결정-기록만-둔다.md) |
| 2026-11-25 | GitHub Actions 버전을 한 단계 이전 메이저(checkout v5 등)로 작성 | Dependabot이 첫 실행에서 업데이트 PR 생성 | 최신 버전으로 올림, Dependabot 주간 확인 유지 |
| 2026-11-25 | `open-in-view: false`인데 컨트롤러가 지연 로딩 구성원 목록을 읽도록 작성 (실행 시 LazyInitializationException) | AI 자체 검토 (테스트 실행 전) | 응답 객체(`HouseholdView`)를 서비스 트랜잭션 안에서 만들도록 변경, `CLAUDE.md` 규칙에 추가 |
| 2026-11-25 | 테스트에서 MockMvcTester 헤더 검증 메서드를 실제로 없는 이름으로 작성 | 컴파일 오류 | 응답 헤더를 직접 읽어 검증하도록 수정 |
| 2026-11-25 | Boot 4에서 위치가 바뀐 `TestRestTemplate` 모듈을 확인 없이 사용하려 함 | AI 자체 검토 (의존성 확인 중) | 이미 포함된 `MockMvcTester`로 대체 |

## 정리
- 사실과 다른 **가정**(사용자 상황, 공개 범위)은 테스트로 잡히지 않았다. 사람이 문서를 읽고 잡았다.
- **버전·API 이름** 같은 오류는 컴파일·CI·Dependabot이 잡았다.
- 그래서 문서 검토(사람)와 자동 검사(컴파일·테스트·CI·Dependabot·gitleaks)를 둘 다 유지한다.
